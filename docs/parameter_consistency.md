# 参数版本变更与一致性核对

本文仅记录相对提交文档的版本更新、参数选用差异，以及文档内部不一致的核对结论。单纯新增方案或参数组无需更新本文。完整参数、来源和兼容备注见 [hamming_parameters.py](../codebased_estimator/hamming_parameters.py)；攻击映射见[模型说明](model.md#内置-hamming-方案的-doom-映射)。

## 版本与选用差异

- **TRIKE：** 采用更新后的 v1.6 规范参数进行估计。
- **QUBE：** 采用提交规范和参考实现的五组配置，排除编码长度超过环长的旧优化配置及其他参数变体。

## 文档内部不一致

- **Mito-1-E-256：** 规范的安全估计部分混用了编码长度 `32256` 与基础环长；按基础参数和参考实现采用 `r=32261`。
- **HEP-QC：** 算法文本及 §6.1 使用扩展长度 `n′=64 ceil(n/64)`，表 4.2 和实现的密文长度则使用 `L=n1*n2`；实际传输长度按后者记录为 `code_length=L`。
