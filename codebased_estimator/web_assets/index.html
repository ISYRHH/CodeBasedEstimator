Model notes

Scope
Results cover the selected recovery routes and algorithms, not whole-scheme security.
Units
All costs are log₂ values in the units shown per row. Memory is not estimated for quantum and local Rank results.
Targets
QCSD counts syndrome targets. QCCF counts acceptable nonzero codewords; omit solutions per syndrome for QCCF.
Minimum cost
Minima include only evaluated, eligible candidates within the same cost family and units. A classical memory limit excludes local Rank estimates with unknown memory from minima. The limit does not apply to time-only quantum estimates.
Assumptions
Open a route or result's details for its model assumptions, sources, and algorithm parameters. JSON exports preserve the complete report.
